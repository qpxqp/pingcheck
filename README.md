# Ping Checker

Пингует IP-адреса из Excel-файла и сохраняет результаты:

- обратно в исходный файл — добавляет колонку
  `YYYY-MM-DD hh:mm:ss` с процентом успешных пакетов по каждому IP.
- отчёт — в отдельный файл `results/YYYY-MM-DD_hh-mm-ss.xlsx`
  (все метрики по каждому IP);

Поддерживает Windows и Linux. Умеет работать без прав администратора (UDP-режим).

---

## Что считается

Для каждого IP выполняется ping (`count` пакетов, по умолчанию 2).
В отчёт попадают:

| Колонка       | Что значит                                                     |
|---------------|----------------------------------------------------------------|
| `ip`          | IP-адрес                                                       |
| `alive`       | `True`, если пришёл хотя бы один ответ                         |
| `success_pct` | процент успешных пакетов, `0..100`                             |
| `ping_count`  | сколько пакетов отправлялось (`--count`)                       |
| `avg_rtt`     | среднее время отклика, мс                                      |
| `min_rtt`     | минимальное время отклика, мс                                  |
| `max_rtt`     | максимальное время отклика, мс                                 |
| `jitter`      | вариация задержки, мс (может быть пусто при <2 ответах)        |
| `packet_loss` | доля потерянных пакетов, `0..1` (не проценты и не количество!) |

### Как считается success_pct

```python
pct = round(recv / sent * 100) if sent else 0
```

- `sent` — сколько пакетов отправили (равно `--count`);
- `recv` — сколько пакетов получили обратно;
- `pct` — доля полученных в процентах, округлённая до целого.

Примеры:

| `--count` | получено | `success_pct` | `alive` |
|-----------|----------|---------------|---------|
| 2         | 2        | 100           | True    |
| 2         | 1        | 50            | True    |
| 2         | 0        | 0             | False   |
| 3         | 2        | 67            | True    |

`if sent else 0` защищает от деления на ноль: теоретически `sent` может
быть 0, если библиотека не смогла отправить ни одного пакета (например,
из-за сетевой ошибки). В этом случае `pct = 0`.

### Что такое packet_loss

Это доля потерянных пакетов от 0 до 1, а не количество:

- 1.0 — потеряно 100% (узел недоступен);
- 0.5 — потеряно 50%;
- 0.0 — потерь нет.

## Установка

### 1. uv

Установите [uv](https://docs.astral.sh/uv/) — менеджер Python-проектов и пакетов.

Windows (PowerShell):

```bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Linux / macOS:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

После установки перезапустите терминал и проверьте:

```bash
uv --version
```

### 2. Репозиторий

```bash
git clone https://github.com/qpxqp/pingcheck.git
```

```bash
cd pingcheck
```

### 3. Зависимости проекта

В каталоге проекта выполните:

```bash
uv sync --no-dev
```

Эта команда автоматически создаст виртуальное окружение и установит все зависимости, объявленные в `pyproject.toml` (pandas, openpyxl, icmplib). Python устанавливать отдельно не нужно — uv скачает подходящую версию автоматически, если её нет в системе.


## Использование

```bash
uv run pingcheck.py
```

По умолчанию:

- входной файл — `ips.xlsx` рядом со скриптом;
- колонка — `ip`;
- 2 пакета на адрес, таймаут 3 с;
- ICMP-режим (нужны права администратора/root);
- отчёты — в `results/`;
- лог — `pingcheck.log` рядом со скриптом (дописывается).

### Аргументы

| Флаг                 | По умолчанию | Описание                       |
|----------------------|--------------|--------------------------------|
| `-i`, `--input-file` | `ips.xlsx`   | путь к исходному Excel-файлу   |
| `--column`           | `ip`         | имя колонки с IP-адресами      |
| `-c`, `--count`      | `2`          | количество пакетов на адрес    |
| `-t`, `--timeout`    | `3`          | таймаут одного пакета, секунды |
| `--no-privileged`    | —            | использовать UDP вместо ICMP   |
| `--no-report`        | —            | не сохранять отчёт в `results/`           |
| `--no-append-source` | —            | не добавлять колонку в исходный файл      |

### Примеры

```bash
# по умолчанию (ICMP, 2 пакета)
uv run pingcheck.py

# UDP-режим, без прав администратора
uv run pingcheck.py --no-privileged

# свой файл и колонка, 4 пакета
uv run pingcheck.py -i hosts.xlsx -col address -c 4

# только отчёт в results/, исходник не трогаем
uv run pingcheck.py --no-append-source

# только колонка в исходнике, отчёт не пишем
uv run pingcheck.py --no-report

# сухой прогон: пингуем, ничего не пишем (кроме лога `pingcheck.log`)
uv run pingcheck.py --no-report --no-append-source
```

### Формат входного файла

Минимально — один лист с колонкой IP (по умолчанию `ip`):

| ip          |
|-------------|
| 8.8.8.8     |
| 1.1.1.1     |
| 192.168.1.1 |

После запуска в этом же файле появится новая колонка с датой-временем
запуска и процентом успеха по каждому IP.

## Права администратора

- ICMP (`--privileged`, по умолчанию) — требует прав администратора
  (Windows) или root (Linux).
- UDP (`--no-privileged`) — прав не требует, удобно для запуска
  по расписанию из-под обычного пользователя.

Если не хотите возиться с правами — используйте `--no-privileged`.

## Запуск по расписанию

### Windows — Планировщик заданий

1. Создать задачу.
2. Действие → Запуск программы.
3. Программа: путь к `uv.exe` (или к `python.exe` в `.venv`).
4. Аргументы: `run <полный путь к pingcheck.py>` (для `uv`)

5. Рабочая папка: папка со скриптом.

Если при запуске по расписанию появляется лишнее консольное окно, используйте `uvw.exe` вместо `uv.exe` в поле «Программа или скрипт».

```bash

```

## Логи

Пишутся в `pingcheck.log` рядом со скриптом в режиме дописывания.
Формат:

```text
2026-11-03 14:05:09 [INFO] ===== Process started =====
2026-11-03 14:05:09 [INFO] В файле `.../ips.xlsx` найдено 3 IP
2026-11-03 14:05:11 [INFO] Пинг 3 адресов...
2026-11-03 14:05:12 [INFO] Успешно: 2
2026-11-03 14:05:12 [INFO] Неуспешно: 1
2026-11-03 14:05:12 [INFO] Результаты сохранены в `.../results/2026-11-03_14-05-09.xlsx`
2026-11-03 14:05:12 [INFO] ===== Process finished =====
```

Файл растёт без ротации — при частом запуске следите за размером.

## Коды выхода

| Код | Когда                                                          |
|-----|----------------------------------------------------------------|
| 0   | успех                                                          |
| 1   | файл не найден / нет колонки / ошибка пинга / нет прав доступа |
| 2   | нет зависимости (openpyxl) или непредвиденная ошибка           |

## Ограничения

- Перезапись исходного файла через `pandas.to_excel` уничтожает
  форматирование, формулы, другие листы и объединённые ячейки.
  Если это важно — используйте только отчёт в `results/`, а запись
  в исходник отключите.
- `icmplib` не поставляет type stubs; для mypy добавьте
  `ignore_missing_imports = true` для `icmplib.*`
  (и `pandas-stubs` для pandas).
- На Windows запись в исходный файл упадёт, если файл открыт в Excel
  (PermissionError). Скрипт это перехватывает и пишет в лог.
